# VerdeAI v9.6.5 — One-Screen First-Time Entry

## Goal
Make the first Android screen understandable in about three seconds.

## Changes
- Replaced the abstract headline and internal product jargon with one plain-language promise.
- Reduced the opening decision to one primary action: **Choose a photo**.
- Kept one quiet secondary action: **Try an example instead**.
- Removed the shaded self-test, onboarding strip, tester instructions, technical cards, tabs, and build clutter from the initial screen.
- Added a small browser-only privacy note.
- Added **Continue saved result** only when a previous result actually exists.
- After choosing a photo, VerdeAI moves directly to the clue step.
- After trying the example, VerdeAI moves directly to the completed possibilities board.
- Reset returns to the simple entry screen.

## Safety
Real AI rendering remains disabled. Backend remains disconnected. Provider calls remain off. API keys remain absent. Paid calls remain locked.
