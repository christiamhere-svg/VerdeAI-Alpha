# VerdeAI v9.7.0 — Visual Credibility Reset

## Purpose
Bring the Futures Board closer in spirit to the aspirational benchmark:
- visually rich,
- emotionally clear,
- immediately understandable,
- distinct future directions,
- worth showing to testers.

## Implemented direction
1. Kept the real property photo as evidence/current state.
2. Kept the simple placement-map logic available.
3. Stopped making weak overlay-first cards carry the full visual burden.
4. Promoted each future using a larger inspiration-led hero presentation.
5. Reduced the feel of placeholder / debug output in the board itself.
6. Preserved all safety locks and the free-only workflow.

## Main UI change
Each future card now includes:
- a premium status row,
- a large real-world inspiration hero image,
- a property-photo inset with calibrated map,
- stronger title/subtitle treatment,
- a short “What it brings” statement,
- three concise highlights,
- a one-tap action to open that future.
