# VerdeAI v10.0 — Whole Board First

## Purpose
Return to the original visual promise: one complete, coherent, shareable property board before secondary controls.

## Primary result
- Original property photo on the left.
- Six visibly different futures in the centre.
- VerdeAI recommendation, compass and oracle on the right.
- Next steps and five-year evolution across the bottom.
- A full-board overlay for phone zooming and desktop inspection.

## Honest boundary
The golden example uses six prepared same-property images. Real uploaded photos use imported images when available; without them, the board labels the missing future image instead of pretending a transformation exists. Real AI rendering remains disabled.
